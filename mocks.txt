DEMANDE  (POST /api/Demande)
================================================================================
POST http://localhost:5201/api/Demande
Content-Type: application/json

{
  "agentId": 1,
  "typeDePretId": 1,
  "dateDepot": "2026-08-01T10:00:00",
  "montantDemande": 20000
}

(Le NumeroDossier est généré automatiquement côté serveur : D-AAAAMMJJ-XXXXXXXX)

RÈGLES D'ÉLIGIBILITÉ qui peuvent bloquer (réponse 400) :
  - agentId inexistant / typeDePretId inexistant
  - agent titularisé depuis moins d'un an          -> "Ancienneté minimale d'un an non respectée"
  - montantDemande > plafond du type de prêt       -> "dépasse le plafond"
  - franchise non respectée (même type < FranchiseMois)
  - salaireMensuel absent ou nul                     -> "Salaire mensuel non renseigné"
  - taux d'endettement > 40%
    (mensualités existantes + montant/dureeMaxMois) / salaireMensuel
  - catégorie Logement : cumul des montants accordés
    (décisions favorables + demande courante) > 30 000 DT

GET  http://localhost:5201/api/Demande
GET  http://localhost:5201/api/Demande?agentId=1&statut=0&typeDePretId=1&from=2026-01-01&to=2026-12-31
GET  http://localhost:5201/api/Demande/{id}

POST http://localhost:5201/api/Demande/{id}/pieces
Content-Type: multipart/form-data
  file      = (choisir un fichier, ex. cin.pdf)
  typePiece = "CIN"

POST http://localhost:5201/api/Demande/pieces/{pieceId}/status
Content-Type: application/json

{
  "statutVerification": 1,
  "auteur": "RH",
  "commentaire": "Pièce conforme"
}
(statutVerification : 0=EnAttente, 1=Conforme, 2=NonConforme)

POST http://localhost:5201/api/Demande/{id}/cloturer-depot
Content-Type: application/json

{
  "auteur": "RH",
  "commentaire": "Dossier complet"
}
Résultats : 204 si OK, 400 si pièces obligatoires manquantes ou non conformes.

POST http://localhost:5201/api/Demande/{id}/transition
Content-Type: application/json

{
  "newStatut": 2,
  "auteur": "RH",
  "commentaire": "Transmission au comité"
}
(newStatut : voir enums StatutDemande. Transitions autorisées :
  Deposee(0)      -> Enregistree(1), AEtude(2), Rejetee(9)
  Enregistree(1)  -> AEtude(2), Rejetee(9)
  AEtude(2)       -> PVVise(3), Ajournee(8), Rejetee(9)
  PVVise(3)       -> Signee(4), Rejetee(9)
  Signee(4)       -> DecisionNotifiee(5)
  DecisionNotifiee(5) -> RetenueProgrammee(6), DecaisseeCloturee(7))

TESTS DES RÈGLES D'ÉLIGIBILITÉ (réponses 400 attendues)
================================================================================
A) Plafond dépassé
   POST /api/Demande
   { "agentId": 1, "typeDePretId": 1, "dateDepot": "2026-08-01T10:00:00", "montantDemande": 999999 }
   -> 400 "Montant demandé ... dépasse le plafond ..."

B) Franchise non respectée (2e demande même type < 12 mois)
   POST /api/Demande
   { "agentId": 1, "typeDePretId": 1, "dateDepot": "2026-08-01T10:00:00", "montantDemande": 5000 }
   -> 400 "Franchise non respectée: il faut attendre 12 mois..."

C) Ancienneté < 1 an
   Créer un agent avec dateTitularisation = "2026-01-01T00:00:00" puis POST /api/Demande
   -> 400 "Ancienneté minimale d'un an non respectée"

D) Taux d'endettement > 40%

   (mensualité ≈ 833 → 833/500 = 167% > 40%)

   -> 400 "Plafond cumulé logement dépassé"

   -> 400 "Dossier incomplet: pièces obligatoires manquantes: CIN, Bulletin de salaire"
